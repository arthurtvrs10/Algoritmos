## 📂 Organização do Repositório

```

│   └── Lógica e Controle de Fluxo
```

## ⚡ Como Executar os Códigos

### 🔹 Executando Códigos em C
```bash
# Compilando com gcc
gcc -o output "Atividade de C/seu_arquivo.c"

# Executando
./output
```

### 🔹 Executando Códigos em Java
```bash
# Compilando e executando
javac Algoritmos-em-Java/SeuArquivo.java
java Algoritmos-em-Java/SeuArquivo
```

### 🔹 Executando Códigos em JavaScript
```bash
# Executando com Node.js
node "Algoritmos Js/Curso_JS/Section_2/index.js"
```
